Carry is a Chrome extension that writes every ChatGPT, Claude, and Grok
conversation to a folder on your computer as plain Markdown. Automatically.
Local-only. No server.

[Install it from the Chrome Web Store](https://chromewebstore.google.com/detail/carry-%E2%80%94-save-chatgpt-clau/mlligjaffhiphbpkjejefoibcclbdfll).

## Why

The useful thinking happens in a chat box that can vanish. Grok has no real
export and permanently purges deleted chats after 30 days. Official takeouts
are JSON blobs. One consent toggle, one ban, one 30-day window, and the record
is gone. The only copy that survives is the one you saved while the account
still worked.

## What it does

- Auto-capture for ChatGPT and Claude in the background while Chrome is open.
  Grok syncs with one click.
- One conversation, one Markdown file, named and filed by date and provider.
- Deep Research reports, Canvas docs, Claude projects, Claude Code artifacts,
  Grok DeepSearch. The transcript, and the work around it.
- Writes with the File System Access API. Nothing is uploaded.
- Re-sync matches by id and updates in place. Files you edited by hand are
  never overwritten.
- Works with Obsidian, Logseq, VS Code, or Finder. No plugin, no API key.

## The deal

Free trial, then a lifetime license. No subscription. The files stay yours if
you uninstall.
